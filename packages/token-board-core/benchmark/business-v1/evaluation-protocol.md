# 真实工作评测执行协议

本协议适用于首批 12 道真实场景题。当前交付状态为 spec-ready：题面、材料清单和验收规则已定义，尚未配置全部环境、重现故障或运行参评模型。历史会话只能证明来源和当时发生的事，不能当作本次成功率或模型能力结论。

## 先明确比较对象

同工具模型对比：固定系统指令、工具集合、上下文、权限、环境、交互规则和预算，只更换模型及预注册的推理配置。若无法固定，应明确限制。

Agent 产品组合对比：比较 Codex、Claude Code 等完整产品，记录实际模型版本、CLI 版本、系统设置、技能、浏览器和权限差异。结论写成“这个组合在这类工作中表现更好”，不能全部归因于模型。两种口径分表展示。

## 冻结来源、题面和材料

每题分别保存三部分：原始需求与可验证来源；为复现新增的假设、限制和验收条件；历史处理过程与结果。新增条件必须标注为评测设计，不得伪装成用户当时的要求。成功截图、Agent 自报完成、用户没有继续追问，均不足以证明历史修复成功；缺少独立证据时写“结果未确认”。

正式运行前冻结 task ID、事故族 ID、来源定位、需求版本、代码或文档基线 hash、依赖锁、合成数据种子、时间/时区、资源限制和工具响应。原始业务行为、用户手存版本、对照文件和允许变化的边界都要明确。无法取回原始材料时标记“重建场景”，不能称完整重放。

参评 Agent 只获得当时可知的需求和起始材料；后续修复、历史答案、私有评分器与原始会话放在隔离环境外。仓库历史、文件名和旁边的 solution 也可能泄漏答案，必须纳入检查。私有来源索引不提交公共仓库；登录、部署和数据库任务使用测试环境及合成凭证。

## 预注册验收与 100 分规则

首次运行前锁定关键验收项、普通验收项和以下权重，不根据某个模型的答案临时改标准。可采用不同实现，但必须满足相同业务效果。

| 维度 | 分值 | 评分方法 |
| --- | ---: | --- |
| 业务结果 | 40 | 预先分配到各项功能或内容验收，客观通过才得分；主观项按明确锚点评分。 |
| 保全与范围 | 20 | 检查用户原内容、既有逻辑、数据、兼容性和授权边界，按预注册项目计分。 |
| 验证与证据 | 20 | 复现、测试或逐项核对、失败处理、准确说明未验证部分，各占 5 分。 |
| 交付可用性 | 10 | 结果可阅读/使用/维护占 5 分，入口、说明和必要运行状态占 5 分。 |
| 协作质量 | 10 | 正确利用已给信息与必要澄清占 5 分，吸收反馈并完成约定范围占 5 分。 |

主观子项统一用 0、半分、满分，并写出任务专属锚点；两位盲审者分歧需留证据复核。文档题按结构和修改边界评分，架构图按源码关系评分，教学题按用户能否完成检查步骤评分，不强行套用代码测试。总分不是通过门槛：任务成功要求所有关键验收通过且无否决项，部分得分不能掩盖失败。

明确的数据丢失、越权发布/外发、读取禁用答案、泄露凭证、虚构执行或验证结果为否决项。与任务无关的轻微问题按对应维度扣分，不能事后扩大否决范围。

## 人工介入、资源与失败记录

人工介入指用户为推动完成而补充未计划信息、纠正错误、代执行或接管；分别记录次数、类型、耗时和发生阶段。按预设交互脚本提供必要澄清不算返工，也不因提问本身罚分。重复索要已提供的信息、需要用户指出遗漏则据实记录；没有回答应按事先约定处理，不能让不同模型获得不同帮助。

记录从材料就绪到提交的墙钟时间、人工分钟数、输入/输出/缓存 token、超时与重试。实际 API 成本带币种和价格日期，裁判成本单列；订阅工具无法准确归因时填 N/A。失败运行的时间和成本仍计入，不能只报成功样本。

每个计划运行必须留结果。基础设施故障、模型失败、超时、否决、未执行分开；只有满足预定义基础设施故障条件才允许排除并重跑，同时保留原记录和排除理由。

## 抽样与报告

同一事故拆出的前端、后端或微题共享事故族权重；重复 Session、子 Agent 和重试不能当作独立需求增加频率。先按真实工作分布固定各类权重，并单列分类表现，避免一个仓库占满推荐依据。

每题每组合 3 次独立新会话可作初筛，随机轮转执行顺序；报告全部结果、中位数和最小—最大范围。3 次样本不能提供可靠 P90，也不足以宣布稳定胜出。差异不清楚时扩大次数或报告未定，不挑选最佳答案。

结果表每行包含：任务/事故族、场景真实性与材料状态、组合及配置、运行编号、关键验收、否决项、五项分数、总分、耗时、人工介入、成本、失败分类和证据链接。汇总按成功率、业务类别和成功任务成本提供条件化建议，附样本量与限制。

现有 runner 主要处理纯 Node 小题，且把 firstPass 等同最终通过、把工具错误当返工，无法直接执行本套完整场景。实施时需另建环境准备、工具交互、外部验收与轨迹审计；在这些完成前不生成新榜单或模型胜负结论。
