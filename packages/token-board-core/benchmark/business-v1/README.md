# 个人真实工作评测题库

这套题用于判断什么模型与 Agent 配置更适合你的实际工作。依据 2026 年 9 月 2 日至 10 月 2 日的本机会话，由三个 Agent 分别调研 Codex、其他工具和评测设计，再合并为 12 道来源可追溯的场景题。

从精读案例看，值得重点测的是：在已有项目上定位跨层问题、保留你已经修改的内容、正确吸收反馈，并交付实际能使用且有验证依据的结果。原题库的通用算法得分不能单独回答这些问题。这是对所选案例的归纳，不是对你全部工作时间的统计。

**本版保留 12 道完整场景的题面、材料清单、60 项验收与来源核对。** 其中 B04、B09、B11 已另建[三题流程试点](../business-pilot-v1/README.md)，冻结缩小范围后的输入与评分器，并记录独立 Agent 试跑。这里的 `replayReady: false` 和 `modelRuns: 0` 仅指本目录的完整场景规格；试点结果单独保存，不能冒充完整 12 题或模型排名。原问题来自真实会话，合成数据、故障注入和附加条件均单独标注。

流程试点的代码题区分度不足，现另建 [B02、B04、B09 历史重放](../business-replay-v2/README.md)，恢复更完整的当时材料，并先做难度与评分校验。新版不覆盖本目录规格或旧试点记录。

## 本次读取的范围

| 来源 | 实际覆盖 | 边界 |
| --- | --- | --- |
| Codex | 760 个日志文件，按会话 ID 合并为 382 个；解析元数据和用户消息；排除本次研究的 4 个会话 | 近期活跃主线程经启发式筛选剩 237 个候选；精读 12 个候选场景涉及 11 个主会话，不是人工通读全部对话 |
| Codex 镜像副本 | 378 个重复副本中，345 个与所选副本前缀一致；另 33 个重新解析后没有新增用户文本 | 工具输出仍可能存在差异；不以副本数量增加工作频率 |
| Claude Code 客户端 | 50 个 JSONL，含 39 个主会话和 11 个子代理；解析 25,690 条事件及 277 条历史索引；近期有 17 个活跃主会话 | 历史索引与正文去重；3 个会话仅有索引无正文；精读 10 个候选场景 |
| Cursor | 检查到 4 个本地项目目录，未发现会话正文 | 不能断言其他路径或云端没有历史 |
| Gemini 与 Antigravity | 发现 3 个 2025 年 11 月的 PB 文件，仅检查元数据 | 未解码，未作为近期题目依据 |
| Trae CN | 只读检查 3 个旧状态数据库，未发现近期会话 | 未完整重建旧版会话格式 |
| OpenCode | 检查标准本地存储位置，未发现会话正文 | 不代表其他安装位置不存在记录 |

扫描统计是本次读取时的快照。已过滤明显的子代理委派、探针与本次研究内容；主线程识别仍有启发式限制。用户说“继续”、纠正一句话以及重复记录都不算一个新的业务任务。本次没有读取云端聊天。

日志里既有多个 Codex 模型标签，也有 Claude Code 客户端记录的 Gemini、GLM 标签；代理别名不一定是供应商实际后端身份。历史任务、工具和环境各不相同，因此不能用这些旧会话直接排名模型。

## 如何用来判断适配度

先看各类任务是否通过全部关键验收，再看人工纠正次数、完成耗时和成本。辅助评分为业务结果 40、保全与范围 20、验证与证据 20、交付可用性 10、协作质量 10。总分高不能抵消关键失败；必要澄清和预设的选方案环节不算返工。

比较纯模型时固定工具和环境；比较 Codex 与 Claude Code 等产品时，结论应限定到实际模型、Agent 和工具组合。每题各跑三次可作初筛，报告全部结果和范围，不能据此宣布可靠 P90 或稳定赢家。个人工作权重尚未预注册，本版不生成一个全局推荐分。

详细规则见[执行协议](evaluation-protocol.md)。正式运行前按[材料准备清单](materials-checklist.md)冻结环境与评分器。三题试点使用独立的 `tools/eval-runner/business-pilot.mjs` 导出与验收；旧版 runner 仍不能直接执行这些完整场景，本次没有改动旧榜单或其示例结果。

## 文件与溯源
