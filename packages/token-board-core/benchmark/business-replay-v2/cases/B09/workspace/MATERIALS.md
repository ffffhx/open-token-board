# 材料说明

仓库文档的候选提交为 `cb414f0586b0bc78090b2c59d7e47ea38ebaa95d`，对应 Git blob 为 `e6c0a732d0b0b394f8483eab370d8c9202438f2f`。它与历史 diff 的旧 blob 精确匹配，但记录没有证明当时完整仓库的 HEAD；也不能用该提交替代用户已保存的未提交工作内容。

- `handbook.md` 是该次会话中的工作文档，包含完整章节与当时尚未提交的差异。
- `.history/repository-document.md` 是会话附近可达的仓库文档快照。它用于对照，不能据此认定工作树与仓库相同。
- `.history/tool-events.jsonl` 是历史会话中与这两份文档有关的工具调用、工具结果和用户消息的节选，保留原始时刻及操作类型。未包括后续处理结果。
- `references/defense-notes.md` 由记录中对另一份文档的两次 Read 拼接，保留全部可见的文字。原图附件不在题包内，对应位置只保留图注与原文件名；链接已经替换为不可访问的脱敏占位地址，不需要打开。

工具事件每行是一项 JSON 对象。`eventId` 仅供引用；`timestamp` 使用 UTC；`type` 为 `tool_use`、`tool_result` 或 `text`。调用与结果用 `toolUseId` 配对；调用保留 `name` 与 `input`，结果保留 `content` 与 `isError`。Read 结果里的 `行号\t内容` 是当次读取时的文件行号，不是 JSONL 行号；不同时间的同一行号可能已经对应不同内容。Edit 的 `old_string` 与 `new_string` 为原工具参数，`replace_all` 保留原值。PowerShell 结果可能有非零退出码，不能将工具文字本身当作成功承诺。

其中一个工具结果原本保存在单独文本文件；导出时将其全文内联，并附 `exportNote` 说明。工具事件不是连续的操作系统审计记录；没有原生编辑器保存事件或完整的工作树快照。用户消息是保存行为的一项证据，具体内容需结合文件读取与编辑记录判断。

所有文件均是离线脱敏导出：人名、学校、雇主、内部工具标识、路径与链接经过一致替换；时间和原始业务数字保留；换行统一为 LF。外部链接占位符和缺失图像不是本题要求修复的对象。题包未给出的源码、内部 Wiki、截图或平台能力不可自行补作事实。
