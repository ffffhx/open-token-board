项目 1 按 [references/project-notes.md](references/project-notes.md) 整理为定位、业务背景与难点、方案设计和落地结果：

- 业务背景：商业化拦截与支付流程需要真实登录态验证，支付环节需要人工介入。
- 难点：评测 5 款主流工具后发现，现有工具普遍无法解决开发者与 Agent 抢占 Chrome 窗口与焦点的问题。
- 方案：Gateway 集中管理已登录 Profile 资源与租约并动态分配；Wrapper 申领一次性 Ticket、Daemon 使用 WebSocket 长连接、CDP 经 Gateway 安全校验后通过专用管道转发；页面悬浮控制条支持暂停、接管与恢复。
- 结果：日常并行运行 2 个独立 Agent 浏览器 Session，支持多需求并行开发与自动化验证。

保留了资料支持的“我设计并落地”的个人贡献表述。未沿用旧稿中资料未支持的 Profile 隔离复制与事务同步、Chrome 136 限制、controlGeneration、严格排他租约细则、原生 Input Guard、系统级拦截、跨平台支持状态、崩溃恢复及无损保证等细节，也未补充个人踩坑经历或测量结果。
