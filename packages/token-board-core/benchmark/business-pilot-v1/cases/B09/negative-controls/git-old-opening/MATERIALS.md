# 材料与范围

这是历史工具读取与编辑记录的脱敏节选。它保留了三个不同版本的开场白及其先后关系。没有完整原仓库历史、原生编辑器数据或 Ctrl+S 事件日志。

本次任务仅处理 handbook.md 的整体开场白和「项目 1」。项目 2 是相邻受保护内容，逐字节保留。所有历史与参考材料都只读。

.history/git-head.md 的开场白、项目 1 来自历史 Git blob；项目 2 为便于限定本次编辑范围，统一使用当前工作副本内容。read-02.md 的开场白和项目 1 来自首次助手误改前的 Read/旧文本；read-03.md 来自第一次助手改写；当前 handbook.md 来自后一次修改后的状态。材料顺序见 .history/events.json。

私人姓名、学校、雇主、内部系统与部分数字经过稳定替换；文件统一为 UTF-8、LF。后续字节一致性指的是这些脱敏材料，不是原文件物理字节。
