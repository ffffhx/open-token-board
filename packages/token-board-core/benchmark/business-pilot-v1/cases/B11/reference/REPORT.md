# 本地发布验证

故障来源是发布命令只构建并复制静态站点，未更新实际提供私有正文的独立内容卷。构建成功不能证明正文更新。初始作者请求返回 HANDOVER-V1，而编辑后的 Markdown 已是 HANDOVER-V2。

修改 scripts/release.mjs，让同一命令依次构建、导出指定文章的 JSON 和 HTML、同步指定文章到内容卷，再发布静态壳。按 slug 复制两个产物，未发布其他草稿，也不删除数据卷中独有的文章。

验证命令：在评审目录运行 `node verify.mjs reference`。验收通过独立临时副本启动两个 loopback HTTP 服务，先确认旧正文，再执行发布，实际读取 JSON 和受保护 HTML；并检查匿名/普通读者403、其他文章字节保持、重复发布，以及追加随机正文后再次发布。具体结果以评审保存的运行报告为准。

验证范围仅为本地 HTTP 内容与权限，不包含生产端、真实OAuth、SSH/Docker、网络中断恢复、浏览器交互和页面布局。没有声称验证历史线上发布结果。
