# Open Token Board 可访问性与性能审计（2026-07）

## 范围

- 页面：`/`、`/board`、`/u`、`/limits`、`/wrapped`、`/card`
- 组合：浅色/深色 × 桌面 `1440x1000` / 移动 `390x844`
- 说明：当前 worktree 未包含并行开发中的 `account-usage-panel` 新“效率指标”分区，本轮未审计该新增分区。

## 严重项

1. 图表键盘操作不完整：`/board` 日趋势柱、小时下钻柱、行内 sparkline 只有鼠标 hover/click 路径。已修复为 `role="button"`、`tabIndex=0`，Enter/Space 可触发，`:focus-visible` 通过 token 色描边。
2. 进度信息缺语义：额度、目标、等级、会话占比、榜单占比只是视觉条。已补 `role="progressbar"`、`aria-valuemin/max/now` 和中英文字典 aria 文案。
3. 表格缺少可读标题：榜单和个人会话表无 caption。已补 `sr-only` caption，并为排序表头补 `aria-sort`。
4. 触控目标不足：若干导出、复制、安装、目标表单按钮低于 44px。已统一到 `min-h-11`，表单控件补 `name`/`autoComplete`/`inputMode`。
5. 公开资料页热力图误入过长 Tab 序列：365 个 11px 小格不适合作为按钮，也无法满足 44px 触控目标。已改为整体 `role="img"` 摘要语义，小格保留鼠标 title，滚动区域补简洁 `aria-label`。

## 建议项

1. 首屏跳转：全站补 skip link 到主要内容。
2. 分享图片依赖：`html-to-image` 原本进入 `/u`、`/wrapped`、`/card` 首屏包。已改为点击保存/复制时动态 import。
3. 文件存储快照刷新：50 用户 × 90 天数据下，快照 cache miss 会重复读/解析事件文件。已改为文件存储刷新快照时只读一次事件，Postgres 路径保持原行为。
4. 对比度脚本：新增 `scripts/audit-a11y.ts`，使用 Playwright 截图像素取样计算 WCAG AA，同时检查 44px 触控目标和记录 Tab 序列。
5. 压力脚本：新增 `scripts/audit-board-stress.ts`，生成 50 用户 × 90 天数据，验证 90D 榜单渲染、长任务和图表交互是否影响榜单 DOM。

## 验证摘要

- `pnpm exec tsx scripts/audit-a11y.ts`：6 页面 × 明暗 × 桌面/移动，对比度和 44px 触控目标全部 PASS。
- 键盘走查（桌面/浅色）：各页先到 skip link，再进入导航、语言切换、主题切换和页面主操作；`/board` 可到范围 radio、日期输入、图表点位；`/limits` Tab 组为 `tablist/tab`；`/u` 热力图只保留整体滚动区域焦点。
- `pnpm exec tsx scripts/audit-board-stress.ts`：API live 90D 99ms，snapshot 90D 14ms；页面 ready 3136ms，50 行；图表交互 1050ms，long task 1 个、最大 56ms，榜单 DOM mutations 0。
- `prefers-reduced-motion`：现有 `motion-safe` / `prefers-reduced-motion` 样式保留，新增焦点和语义改动未引入强制动画。

## 遗留说明

- 公开资料页热力图小格没有逐格键盘下钻。原因：单格为 11px 视觉单元，逐格进入 Tab 会产生 365 个焦点且无法满足 44px 触控目标；当前以整图摘要和鼠标 title 覆盖。
- 本轮未引入新的运行时依赖；审计脚本复用 Playwright、tsx 和 Node 内置 PNG 解码。
